### **🔍 `Long` 타입에서 `isEmpty()` 오류 및 해결 방법**  

#### **문제점**  
현재 코드에서 `stockId`는 `Long` 타입인데, `isEmpty()` 메서드를 호출하고 있어서 컴파일 오류가 발생합니다.  
`isEmpty()`는 `String`, `List`, `Map` 등의 컬렉션에서 사용 가능한 메서드이며, `Long` 타입에서는 사용할 수 없습니다.

#### **해결 방법**  
- `Long` 타입에서는 `isEmpty()` 대신 `null` 체크만 하면 됩니다.

```java
if (stockId == null) {
    throw new CustomException(ErrorCode.STOCK_CODE_EMPTY);
}
```

#### **잘못된 코드 (컴파일 오류 발생)**  
```java
if (stockId == null || stockId.isEmpty()) { // ❌ Long 타입에서 isEmpty() 사용 불가능
    throw new CustomException(ErrorCode.STOCK_CODE_EMPTY);
}
```

#### **올바른 코드 (컴파일 오류 해결)**  
```java
if (stockId == null) { // ✅ null 체크만 하면 됨
    throw new CustomException(ErrorCode.STOCK_CODE_EMPTY);
}
```

### **최종 수정된 코드**
```java
public StockResponse getStockByStockId(Long stockId) {
    // stockId가 null인지 확인 (isEmpty() 제거)
    if (stockId == null) {
        throw new CustomException(ErrorCode.STOCK_CODE_EMPTY);
    }

    // stockId가 DB에 있는지 검증
    SqlSession session = factory.openSession();
    stockDAO.setSession(session);

    Stock stock = stockDAO.selectStockByStockID(stockId);

    // DB에 주식이 없으면 예외 발생
    if (stock == null) {
        throw new CustomException(ErrorCode.STOCK_CODE_NOT_FOUND);
    }

    session.close();

    System.out.println("stockService");
    System.out.println(stock);

    // KIS Client 연결
    try {
        String response = kisClient.getCurrentPrice("J", stock.getStockCode());

        // JSON 파싱
        JsonNode root = objectMapper.readTree(response);
        JsonNode output = root.path("output");

        // 필요한 필드 추출
        String stockName = output.path("bstp_kor_isnm").asText();
        int currentPrice = output.path("stck_prpr").asInt();

        // DTO 객체 생성 및 반환
        return new StockResponse(stock.getStockCode(), stock.getStockName(), currentPrice);

    } catch (Exception e) {
        e.printStackTrace();
        return null;
    }
}
```

이제 `Long` 타입에서 `isEmpty()` 호출로 인한 오류가 발생하지 않으며, `null` 체크가 올바르게 수행됩니다.
